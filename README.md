# MiniLedger

A loan tracking app to manage money lent to friends, track repayments, and identify overdue loans.

## Setup

**Prerequisites:** Node.js, npm, and PostgreSQL.

### 1. Clone the repository

```bash
git clone https://github.com/Ajeesh6/MiniLedger.git
cd MiniLedger
```

### 2. Set up the database

Create a PostgreSQL database named `miniledger`.

Run the following SQL in that database:

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    phone VARCHAR(20) UNIQUE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE loans (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    friend_name VARCHAR(100) NOT NULL,
    amount NUMERIC(12, 2) NOT NULL CHECK (amount > 0),
    due_date DATE NOT NULL,
    is_repaid BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 3. Run the backend

```bash
cd backend
npm install
```

Create a `.env` file inside `backend`:

```env
PORT=5000
DB_HOST=localhost
DB_PORT=5432
DB_NAME=miniledger
DB_USER=postgres
DB_PASSWORD=your_postgres_password
JWT_SECRET=your_secret_key
```

Start the backend:

```bash
npm run dev
```

### 4. Run the mobile app

Open a second terminal from the project root:

```bash
cd mobile
npm install
```

In `mobile/src/services/api.js`, set `API_BASE_URL` to `http://localhost:5000` for browser testing on your computer.

For testing on a physical phone, use your computer's local IP address instead of `localhost`. Ensure both devices are connected to the same Wi-Fi network.

Start Expo:

```bash
npx expo start
```

Follow the Expo instructions to open the app.

**Note:** The OTP is generated by the backend and printed in its terminal. No SMS is sent.
